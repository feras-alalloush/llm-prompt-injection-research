# تعليمات تشغيل المشروع — للفريق

المشروع: **ShopEase Baseline / Protected**  
مقرر: IT663 — Prompt Injection Defense

---

## 1) ماذا استلمت؟

المجلد: `llm-prompt-injection-research/`

قد يشمل الشخص 1 ملف `.env` وفيه مفتاح Groq جاهز للتجربة المشتركة.  
إذا وُجد الملف وداخله مفتاح يبدأ بـ `gsk_` يمكنك تخطي خطوة إنشاء مفتاح جديد مؤقتاً.

> تنبيه: المفتاح مشترك للفريق فقط. لا تعيد رفعه على GitHub عام أو جروبات عامة.

---

## 2) إذا لم تجد ملف `.env` أو المفتاح لا يعمل

1. افتح: https://console.groq.com/keys  
2. سجّل الدخول.  
3. أنشئ **Create API Key**.  
4. انسخ المفتاح.  
5. أنشئ ملف `.env` بجانب `requirements.txt` واكتب:

```
GROQ_API_KEY=gsk_الصق_مفتاحك_هنا
```

---

## 3) تثبيت المتطلبات وتشغيل المشروع

### أ) الدخول لمجلد المشروع
```powershell
cd المسار\إلى\llm-prompt-injection-research
```

### ب) إنشاء البيئة الافتراضية
```powershell
python -m venv .venv
.\.venv\Scripts\activate
```

### ج) تثبيت المكتبات
```powershell
pip install -r requirements.txt
```

المتطلبات:
- streamlit
- openai
- python-dotenv
- pandas

### د) التشغيل

**Baseline (بدون حماية):**
```powershell
streamlit run app/baseline_app.py
```

**Protected (مسار الحماية — للشخص 3):**
```powershell
streamlit run app/protected_app.py
```

المتصفح عادة: `http://localhost:8501`

## 5) مشاكل شائعة

| المشكلة | الحل |
|---------|------|
| `No module named streamlit` | فعّل `.venv` ثم أعد تثبيت `requirements.txt` |
| خطأ API / 401 | تحقق من `.env` ومن صحة المفتاح |
| خطأ 429 | وصلت لحد الاستخدام المجاني؛ انتظر ثم أعد المحاولة |
| `requirements.txt` غير موجود | تأكد أنك داخل مجلد `llm-prompt-injection-research` |
